# Changelog

Every subproject — the service, the Rust, Python and TypeScript clients and the TUI — carries
the same version, so this is one changelog for all of them. Sections after 0.1.0 are
generated by `scripts/release.sh` from the `Changelog:` trailers described in
[CONTRIBUTING.md](CONTRIBUTING.md); 0.1.0 itself predates them and is written by hand.

## [0.1.0] - 2026-09-23

The first release.

- **Three primitives, one forward pass each.** `noul` (how likely yes), `choice` (one of up to
  20 options) and `score` (a level on a rubric of 2–10), all read from the probability
  distribution over the first generated token. Missing labels are reported as bounds and
  flagged `truncated`; every answer carries its `raw_logprobs`.
- **An HTTP service** at `/v1/systemone`, `/v1/models` and `/health`, with a generated OpenAPI
  contract in `spec/openapi.json`. It listens on loopback by default, caps a request at 32
  questions, refuses unknown fields, and validates the whole request before any model is
  loaded.
- **Hosts:** Ollama natively, and vLLM, llama.cpp, LM Studio and OpenAI-compatible endpoints
  through `/v1/chat/completions`, each with the sampling options that keep the reported
  distribution untruncated.
- **Clients** for Rust (`cerno-sdk`), Python and TypeScript, all tested against the shared
  conformance cases in `spec/conformance/cases.json`.
- **A terminal front end**, `cerno-tui`, built on the Rust client.
- **A measured default model**, `gemma4:e2b-it-qat`, chosen by `cerno-bench`; the comparison is
  in `docs/model-selection.md`.
