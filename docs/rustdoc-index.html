cerno

Noul, Choice and Score — JEV’s system-one primitives — against a locally hosted model. Each question is one forward pass: the answer is read from the probability distribution over the first generated token. The README has the overview, and model-selection.md the measured model comparison.

Crates

cerno_typeswire types — serde always, utoipa behind a feature
cerno_hostModelHost trait, the Ollama and OpenAI-compatible adapters
cerno_corelabels, prompt, logprob maths, engine
cerno_serverthe HTTP service, axum + utoipa
cerno_openapicerno-server’s binary that prints spec/openapi.json
cerno_sdkRust client
cerno_tuiterminal front end, on cerno-sdk
cerno_benchmodel benchmark, not published

The other SDKs

The Rust client has two siblings, written by hand against the same OpenAPI document and tested against the same conformance cases:

  • Python — uv add cerno-sdk, imported as cerno
  • TypeScript — npm install cerno-sdk
